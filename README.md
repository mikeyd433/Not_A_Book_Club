# Not A Book Club (NABC)

A private web app for a small friend group to read books at their own pace
and discuss them without spoilers — chapter-locked discussion threads, per-
reader progress tracking, cover uploads, and more.

See **[SPEC.md](./SPEC.md)** for the full product spec and current build
status, and **[CLAUDE.md](./CLAUDE.md)** for dev setup.
